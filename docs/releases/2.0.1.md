# AudioBridge 2.0.1

Android 与 Windows 的正式版，统一版本号为 2.0.1，继续使用兼容的 WFAS v2 协议。Android 整合含 VPN 回包端口修复的最新 test21；Windows 整合 vpn.9 的功能和修复。

## 主要变化

- 两端提供自适应延迟，以及可输入整数毫秒的手动延迟；延迟设置是缓冲目标，不是声学端到端延迟测量。
- 多音源接收、独立音量与记住音源；保留可选发送端本机播放和远端音量控制。
- Android 改善静音后恢复、播放队列与时钟校正、模式切换和前台通知；修复 VPN 改写握手回复端口造成无法连接的问题。
- Windows 改善集中到达音频的缓冲和连续播放、息屏期间的有效音频保活、静音时钟恢复，周期路由检查不再阻塞收包。
- Windows 修复每源延迟保存、输出设备选择、音量即时平滑生效、启动自动连接，以及等待授权或更正密钥后的连接恢复。
- Windows 修正输出初始化失败时的资源归还顺序，避免还没用完重试次数就提前停止；Android 减少每批小音频包中重复的恢复检查和播放头查询，保留原有缓冲目标与停滞恢复机制。
- 保留中文界面、托盘控制、诊断导出和命令行支持；更新提示使用 AudioBridge 自有版本通道。

## 下载、安装和升级

- **Android：** 下载 `AudioBridge-Android-2.0.1.apk`。正式包名为 `io.github.mu23xr.audiobridge`，沿用 test16／1.3.1 的永久签名，可在相同签名线上覆盖升级并保留数据。历史 #153 的旧签名不能覆盖升级。
- 独立测试包 `.test` 与正式包可以共存，但测试包数据、权限和 Shizuku 授权不会自动迁入正式包。不要同时启动两个发送捕获。
- **Windows 10/11 x64：** 完整解压 ZIP，运行 `AudioBridge/AudioBridge.exe`；保留 app 和 runtime 文件夹，无需另外安装 Java。TAR.GZ 提供相同程序内容。
- Windows 正式版沿用旧正式版配置；测试版的 `audiobridge-test` 配置保持独立，不自动迁入。
- `SOURCE_COMMIT.txt`、`provenance.json` 和 `SHA256SUMS.txt` 用于核对统一源码与附件；请勿只复制单个 EXE。

## 已知限制

- 厂商后台电源管理、息屏和过夜运行仍需更多真实设备验证；系统强停无法仅靠前台通知避免。
- 某些 VPN/TUN 配置仍可能接管局域网 UDP 或多播；修复握手端口不等于兼容所有 VPN 设置。
- Shizuku 发送的安全模式仍限 OFF；部分 Android 自动重连可能需要重新开启非持久发送端。
- 短时真实音乐播放已确认连续；自动检查和模拟器测试不代表所有设备的长连、音质或声学延迟均已验收。相关问题继续跟踪。

本版附件由同一个确定源码提交在 GitHub Actions 构建；不会将历史测试 APK 或本地程序改名作为正式包。
