# AudioBridge PC 1.3.1-test.21-vpn.3

这是 Windows x64 PC 预发布版，只提供电脑版安装包。

- 接入目前的 test21 PC 功能：多源接收、自适应或手动整数延迟、独立音量、中文界面、托盘控制和诊断导出。
- 修正 PC 接收播放的缓冲容量与目标不一致、低延迟时钟校正过猛，以及大延迟起播时的小包裁剪。
- 自动更新检查只提示可以安装的更新，不再因本地版本较新自动弹窗。

已知限制：冷启动仍可能裁掉开头的一小段声音。手机/平板到 PC 的实际听感和长时间无线稳定性仍待验证，不代表所有音质问题已经解决。

解压完整 ZIP 后运行 AudioBridge-Test/AudioBridge-Test.exe；保留 app 和 runtime 目录。预览版使用独立的 audiobridge-test 配置，不自动升级为稳定版。

附件由该版本的 GitHub Actions 从准确提交重新构建。SOURCE_COMMIT.txt、provenance.json 和 SHA256SUMS.txt 记录其来源与校验；它与此前本地参考包的构建环境、文件哈希可能不同。没有重签或修改 Android 应用。

本版与此前本地 vpn.2 的接收修复逻辑相同；递增版本用于修复首次预发布时的 GitHub 草稿查找流程，保持已有标签来源不变。
