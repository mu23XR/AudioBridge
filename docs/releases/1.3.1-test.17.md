# AudioBridge 1.3.1-test.17（独立测试通道）

Android 包名为 `io.github.mu23xr.audiobridge.test`，永久签名与 test.16 相同，名称 AudioBridge 测试并带 T 图标标记。它安装在 test.16/正式版旁边，设置与权限独立，不需要卸载正式版。同一设备先停止原版发送/接收，再运行测试版，避免音频采集和端口争用。

- 延迟仅有自适应/手动选择；手动支持无级 20–400 ms 与数字输入，保留旧手动值。自适应 20–80 ms，按有效音频的连续欠载/健康间隔调整。设置为接收端本地缓冲目标，重新连接生效。
- 播放看门狗对持续欠载、停止进度和无效局部恢复升级重建；失败清理资源并正常重连，单播/多播统一健康策略。重连不重复完整连接提示音。
- WFAS 运行通知合入发送/接收/关闭操作，隐藏重复的普通模式通知；音量入口仍可用。多服务并存尚不能保证全场景只有一条通知。
- 独立测试包只检测独立 Preview 资产，排除旧正式包名测试版；正式通道仅选语义版本稳定 Release。修正同版本正式/预发布排序。

本版需真机长时间和锁屏验收，不宣称 OEM 强停、VPN/TUN 兼容或第一次双端关闭已经解决。WFAS v2 无线协议不变。默认 CI 请求为仅构建，不自动发布。
