# AudioBridge 1.3.1

以 `v1.3.1-test.16`（60137ef976bb4218f8a5deca2181f77cba4a079b）为正式版基线。Android 与 Desktop 产品源码保持 test.16 行为；本次修复正式发布工作流并补充源码坐标和治理检查，不混入尚待验收的 test.17 功能。

## 保留的功能与修复

- 保留 test.13 后的功能，以及作者窗口、赞助入口和自动弹窗的清理。
- 通知发送/接收操作可重复执行；二维码使用 AudioBridge 自有配对格式。
- Shizuku 发送启动同步媒体静音状态，停止/清任务时释放音频路由并恢复原音量。
- 持续零 PCM 使用保活包，接收播放使用非阻塞写入和播放停滞恢复；修正旧连接任务清理及快速模式切换。
- 保留 Desktop Snapcast 连续音量指令修正和协议自检。

## 安装与签名

Android 正式包名 `io.github.mu23xr.audiobridge`，使用 test.16 相同的永久签名。内部版本号高于 test.16，可覆盖升级并保留数据，无需卸载。

SHA-256 证书：`4DDF267D25A73F0A28446C9E77293204E32F6777C63417FEB7BD925040FEFB63`。

历史 Stable #153/test.11 使用不同证书，不能按同一签名线覆盖升级；请先保留必要设置再决定迁移。未来独立测试包使用 `.test` 包名，不覆盖本正式包。

## 已知问题

- 部分设备长时间接收可能欠载、卡顿或无声；新播放看门狗和自适应延迟修正将在独立测试通道验收。
- 系统后台电源管理可能强停应用；前台通知不保证所有厂商系统都会保留进程。
- VPN/TUN 配置可能拦截局域网 UDP，尚未完成兼容修复。

以上问题继续跟踪，不因本版正式发布而关闭。WFAS 仍为 v2。附件提供 Android APK、Windows 包、SHA256SUMS.txt 和 SOURCE_COMMIT.txt。
