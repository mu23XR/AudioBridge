# AudioBridge 2.0.2（Android）

本次正式版更新安卓接收端。短时音频积压会先正常排空，只有持续超出阈值才会裁剪。独立播放线程使用 Android 音频优先级，减少正常接收时因调度延迟造成的队列溢出和断音。

APK 使用原正式包名和签名，可以覆盖安装安卓 2.0.1 并保留设置。WFAS 协议和原有延迟设置兼容。

Windows 的最新程序包仍是 [v2.0.1](https://github.com/mu23XR/AudioBridge/releases/tag/v2.0.1)。

安卓产品源码来自 `main` 的 `7cb412b3735699ea6590933cf3fc6faa93290eac`。请从这个 Release 下载 `AudioBridge-Android-2.0.2.apk`，可用同页的 `SHA256SUMS.txt` 校验。
