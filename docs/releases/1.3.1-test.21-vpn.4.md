# AudioBridge PC 1.3.1-test.21-vpn.4

Windows x64 PC预发布，修复test21接收手机／平板声音时的一条可复现丢音路径，关联 #72、#55。

- 原先软件队列固定60ms，集中到达约100ms音频时会在播放线程取走之前删除真实PCM；现在为突发留出容量，起播等待仍不超过原来的40ms。
- 将软件和原生输出中的积压一起计入延迟预算；短暂突发保留，持续超标才裁剪，避免另叠加一份长期排队延迟。
- 时钟校正使用一段时间内的平均总积压，避免固定采样总撞上批量到达的高点，或漏算留在软件队列中的声音。
- 诊断增加队列容量和持续积压裁剪字节数，便于区分后续故障的来源。

修复前，实际播放器的内存输出测试会删除7800字节音频；修复后该用例保留完整PCM。有限输出模型还覆盖100ms批量到达、±250ppm时钟偏差和40／100ms播放线程暂停。CI完整检查及包校验不等于真实设备听感或过夜验收，#55保持待验证；冷启动开头裁剪等既有问题没有宣称全部解决。

解压完整ZIP，运行AudioBridge-Test/AudioBridge-Test.exe，保留app和runtime目录。完整版本可在程序信息中核对。使用既有预览配置，不修改Android应用或协议；推荐保留可用的test17作为回退。
